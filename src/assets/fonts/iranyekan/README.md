# IRANYekan

فایل‌های فونت ایران‌یکان (woff2 / woff / ttf) را در همین پوشه کپی کنید و دوباره build بگیرید
(فایل build-exe.bat این کار را انجام می‌دهد). نام فایل‌ها مهم نیست؛ وزن از روی نام تشخیص داده می‌شود:
Thin، Light، Regular، Medium، Bold، ExtraBold، Black، ExtraBlack (نسخه‌های FaNum در اولویت هستند و
فونت متغیر IRANYekanX VF هم پشتیبانی می‌شود). مثال:

    IRANYekanWebRegular.woff2
    IRANYekanWebMedium.woff2
    IRANYekanWebBold.woff2
    IRANYekanWebExtraBold.woff2

فونت‌ها داخل همان فایل تکی index.html جاسازی می‌شوند و در نسخه EXE بدون اینترنت کار می‌کنند.
تا وقتی این پوشه خالی است، فونت وزیرمتن استفاده می‌شود.
