# اسکنر هوشمند (Smart Scanner) — نسخه ۴

عکس یا PDF را بیندازید ← لبه‌ها و گوشه‌ها با دقت بالا خودکار تشخیص داده و صاف می‌شود ← «رنگ جادویی» زمینه را ۱۰۰٪ سفید و متن را شفاف و خوانا می‌کند ← PDF آماده چاپ.
کاربر فقط فایل را آپلود می‌کند و بلافاصله خروجی را می‌گیرد.

## تغییرات نسخه ۴

### ۱) بازنویسی کامل موتور تشخیص لبه و گوشه‌ها (v5)
- **مشکل نسخه قبلی**: در برخی عکس‌ها گوشه‌ها صدها پیکسل جابه‌جا می‌شدند یا سیستم مقیاس تصویر به هم می‌خورد.
- **موتور جدید**:
  - **تخمین رنگ پس‌زمینه از لبه‌های کادر**: رنگ و روشنایی میز/سطح از حاشیه‌های عکس سنجیده می‌شود. چه میز تیره باشد چه سفید چه رومیزی یا چوب، سند فوراً از میز تفکیک می‌شود.
  - **نقشه فاصله چندمعیاره**: ترکیب فاصله رنگی، اختلاف روشنایی و کم‌بودن اشباع رنگی کاغذ.
  - **بستن ریخت‌شناسی (Morphological Closing)**: متن و جداول داخل سند مسدود می‌شوند تا خطوط داخل برگه با لبه کاغذ اشتباه گرفته نشوند.
  - **پوشش محدب (Convex Hull) و RDP تطبیقی**: تقریب دقیق ۴ گوشه بر اساس هندسه صفحه.
  - **جستجوی نرمال گرادیان در وضوح بالا**: در نسخه ۱۶۰۰ پیکسلی، امتداد بردار عمود بر لبه برای رسیدن به لبه فیزیکی واقعی کاغذ پیمایش و خطوط با حداقل مربعات کل (TLS) برازش داده می‌شوند.
  - **دقت زیرپیکسلی**: تقاطع خطوط برازش‌شده، گوشه‌های واقعی کاغذ را تعیین می‌کنند.

### ۲) طراحی مدرن بر پایه پاپ‌آپ و شیت معلق (بدون شلوغی و المان‌های ثابت)
- بخش اعظم صفحه به **نمایشگر سند** اختصاص دارد تا کاربر تسلط کامل روی سند داشته باشد.
- **عدم شکستن به ۲ خط**: تمام دکمه‌ها، عنوان‌ها، برچسب‌ها و تگ‌ها به‌صورت تک‌خطی (`whitespace-nowrap`) طراحی شده‌اند و در همه اندازه‌های نمایشگر ظاهر آراسته خود را حفظ می‌کنند.
- **پاپ‌آپ فیلتر و رنگ جادویی**: با زدن دکمه فیلتر، پنجره شیشه‌ای و بسیار روان باز می‌شود:
  - کارت بزرگ و برجسته **رنگ جادویی (Magic Color)** با پیش‌نمایش زنده و بج «پیش‌فرض چاپ».
  - نوار افقی تک‌خطی سایر فیلترها (اصلی، بدون سایه، روشن، خاکستری، سیاه و سفید) همراه با تامبنیل زنده.
  - تنظیمات دقیق جمع‌شونده (روشنایی، کنتراست، پررنگی متن، وضوح) با نوار لغزنده هم‌جهت و دقیق.
  - اعمال یکجا روی تمام صفحات.
- **پاپ‌آپ مدیریت صفحات**: نمایش گرید کارت‌های صفحات، امکان جابه‌جایی ترتیب، حذف یا افزودن صفحه.

### ۳) انیمیشن‌های روان و سرگرم‌کننده
- انیمیشن اسکن لیزری هنگام پردازش عکس‌ها.
- نوار پیشرفت مدرن هدر همراه با گزارش درصد و شمارش صفحات.
- انیمیشن پیش‌نمایش قبل/بعد متحرک در صفحه آغازین.
- افکت انفجار ستاره و تیک متحرک پس از تولید فایل PDF.
- پاسخ‌دهی آنی به کلیک‌ها بدون قفل شدن رابط (Web Workerهای موازی).

### ۴) خروجی باکیفیت و سریع
- رزولوشن استاندارد ۲۵۰ DPI و حالت چاپ ۳۵۰+ DPI.
- فشرده‌سازی هوشمند JPEG با کیفیت بالا (۸۸٪ تا ۹۲٪).
- نوشتن سریع فایل PDF بدون سربار اضافی.

## ساخت فایل EXE کم‌حجم (Tauri)

1. پیش‌نیازها: **Node.js LTS** و **Rust + Visual Studio C++ Build Tools**.
2. روی `build-exe.bat` دوبار کلیک کنید.
3. فایل اجرایی `release\SmartScanner.exe` ساخته می‌شود (حجم حدود ۵ مگابایت، بدون نیاز به نصب).

## نسخه تحت وب
دستور `npm run build` فایل تک‌صفحه‌ای `dist/index.html` را می‌سازد که به صورت آفلاین در مرورگرها کار می‌کند.

## میانبرها
| کلید | عملکرد |
| --- | --- |
| Enter یا Ctrl+S | ساخت PDF |
| Ctrl+O | افزودن فایل |
| Ctrl+V | چسباندن عکس از کلیپ‌بورد |

| R / Shift+R | چرخش راست / چپ |

| ESC | بستن پاپ‌آپ‌ها / خروج از برش |

## موتور تشخیص کاغذ (نسخه ۵ — OpenCV)
تشخیص لبه حالا با **OpenCV** (همان کتابخانه‌ی بینایی ماشین اپلیکیشن‌های اسکنر) انجام می‌شود و کاملاً آفلاین داخل برنامه است. چند روش موازی اجرا و بهترین نتیجه انتخاب می‌شود:
1. **لبه‌یابی Canny** روی چند کانال (خاکستری، روشنایی، اشباع رنگ، فاصله رنگی از میز) بعد از پاک‌کردن متن با فیلتر مورفولوژی → کانتور → چهار گوشه.
2. **ماسک کاغذ**: پیکسل‌های روشن و کم‌رنگ (نسبت به سفیدترین بخش عکس) → خود کاغذ پیدا می‌شود؛ اگر چهار لبه دیده نشود، کادر چرخیده‌ی همان ناحیه برش می‌خورد.
3. **GrabCut** (جداسازی سوژه از پس‌زمینه) برای عکس‌های سخت.
4. **امتیازدهی**: پشتیبانی گرادیان لبه‌ها (با رد انگشت)، تضاد داخل/بیرون، اینکه داخل کادر واقعاً کاغذ باشد (نه گوشی/تبلت) و اینکه کل کاغذ را پوشش دهد.
5. اگر کاغذ کل عکس را پر کرده باشد، کل تصویر به‌عنوان صفحه در نظر گرفته می‌شود.

روی ۱۴ عکس واقعی (کاغذ در دست، میز شلوغ با لپ‌تاپ/تبلت/ماشین‌حساب، پس‌زمینه رنگی) تست شده است. حجم برنامه به‌دلیل OpenCV حدود ۲۰ مگابایت است.

## نصب روی ویندوز (Tauri — بدون Electron)
خروجی یک **فایل نصب (Setup.exe)** با Tauri است: پوسته‌ی بومی Rust + WebView2 خود ویندوز، به‌جای حمل یک Chromium کامل.

**روش ۱ — بدون نصب هیچ ابزاری (GitHub):** پروژه را در GitHub قرار دهید؛ workflow «Build Windows installer» خودکار روی ویندوز اجرا می‌شود. از تب Actions، فایل `SmartScanner-Setup` را دانلود کنید.

**روش ۲ — روی کامپیوتر خودتان:** روی `build-exe.bat` دوبار کلیک کنید (بار اول Rust و Build Tools را نصب می‌کند). نصب‌کننده در پوشه‌ی `release` ساخته می‌شود.

### اجرای همیشگی در پس‌زمینه
- بعد از نصب و **اولین باز شدن**، برنامه خودش را در «اجرا همراه با ویندوز» (به‌صورت پنهان) ثبت می‌کند.
- بستن پنجره برنامه را نمی‌بندد؛ در سینی سیستم کنار ساعت می‌ماند. کلیک دوباره روی آیکون، همان پنجره را **فوری** نشان می‌دهد.
- خروج کامل: راست‌کلیک روی آیکون سینی ← «خروج کامل». هر دو گزینه در تنظیمات قابل خاموش‌کردن است.
